# PyLLM Guard

**Secure LLM applications in Python**

PyLLM Guard is a Python security toolkit concept for LLM applications: prompt injection detection, data-loss prevention, PII redaction, safe output filtering, and audit logging.

🔗 **Live Demo:**  
https://guru-code-expert.github.io/PyLLM-Guard/

---

## Overview

As LLMs move into production, security risks move with them.

PyLLM Guard is designed as an **application-layer security toolkit** that helps teams detect and mitigate common LLM risks *before* they reach users or systems.

---

## What PyLLM Guard Addresses

- 🚨 **Prompt injection attacks**
- 🔐 **Sensitive data leakage**
- 🧹 **PII detection & redaction**
- ⚠️ **Unsafe or policy-violating outputs**
- 🧾 **Audit logging for LLM interactions**

---

## Interactive Scanner Demo

The live demo includes a client-side scanner that:
- Flags suspicious prompt patterns
- Detects emails and phone numbers
- Assigns a Low / Medium / High risk level
- Generates a recommended policy configuration

All logic runs locally for demonstration purposes.

---

## Compliance Support (Non-Certifying)

PyLLM Guard is **designed to help support** compliance efforts such as:
- SOC 2–aligned controls
- GDPR-aware data handling
- HIPAA-supportive engineering patterns

> PyLLM Guard does **not** certify compliance.  
> It provides technical controls that assist compliance programs.
